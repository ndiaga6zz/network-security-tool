# Réponses — TP 1 Git et GitHub

## Question 1 : Quelle est la différence entre git add et git commit ?

La commande git add place les modifications sélectionnées dans
la zone de préparation, appelée index.

La commande git commit enregistre les modifications préparées
dans l'historique du dépôt local, avec un message descriptif.

Ces commandes ne publient pas les modifications sur GitHub.
Pour cela, il faut utiliser git push.

## Question 2 : Que représente un commit dans Git ?

Un commit représente un instantané de l'état du projet
enregistré dans l'historique Git.

Il possède un identifiant et des informations comme l'auteur,
la date et le message décrivant les modifications.

Il permet de suivre l'évolution du projet et de retrouver
des versions précédentes.

## Question 3 : Pourquoi créer une branche plutôt que modifier directement la branche principale ?

Une branche permet de développer une fonctionnalité de manière
isolée, sans modifier immédiatement la branche principale.

On peut tester et vérifier les changements avant de les intégrer.
Cela facilite aussi le travail en parallèle entre plusieurs personnes.

## Question 4 : Quel est le rôle d'une Pull Request dans un projet collaboratif ?

Une Pull Request permet de proposer l'intégration des modifications
d'une branche dans une autre.

Elle permet d'examiner les différences, de discuter des changements
et de faire relire le code avant sa fusion dans la branche cible.
